# VirtualMixDeck（Stream Deck風ショートカット + ローカル/配信 独立音量ミキサー）

専用ハードウェアなしで、アプリ起動・URLを開く・ホットキー送信・音量操作・OBS操作をボタンに登録できるショートカットランチャーと、アプリごとに「自分に聞こえる音量」と「配信に乗る音量」を別々に調整できる音量ミキサーを1つにまとめたWindows向けデスクトップアプリです。基本機能は無料で使えます。

最新版のダウンロードは [GitHub Releases](https://github.com/mumeinoapp/VirtualMixDeck/releases) から。

## セットアップ（開発者向け）

```bash
cd app
npm install
npm start
```

初回起動時は、ヘッダーの「OBS設定」からOBS WebSocketのURL・パスワードを設定してください。音量ミキサーの利用には [Elgato Wave Link](https://www.elgato.com/wavelink) の起動が必要です（VMD側での接続設定は不要で、起動していれば自動で検出します）。

## 実装済み機能

- **ショートカットグリッド**：アプリ起動・URLを開く・ローカル/配信音量操作・ホットキー送信・OBS操作をボタンに登録し、複数ページに分けて管理可能。編集モードではドラッグ&ドロップでボタンの入れ替えができる
- **ローカル/配信 独立2フェーダーの音量ミキサー**：Elgato Wave Link連携により、アプリごとに「自分に聞こえる音量（ローカル）」と「視聴者に届く音量（配信）」を完全に別々のフェーダーで調整。フェーダーのドラッグ・マウスホイールでの1%刻み調整・個別ミュート/一括ミュートに対応し、設定は再起動後も保持される
- **OBS連携**：OBS WebSocket経由で、配信の開始/停止・シーン切り替えをボタンから操作（音量調整はOBSではなくWave Link連携側の機能）
- **カスタムアイコン**：ボタンごとに用意されたSVGアイコンを選べるほか、自分の画像をドラッグ&ドロップして登録することも可能
- **プリセット管理**：全ページ分のショートカット構成をまるごと名前付きで保存・切り替え

## アップデート確認機能

メニューバーの「バージョン」から、現在のバージョン表示・確認・（見つかった場合の）ダウンロード・再起動して適用ができます（ウィンドウやパネルは出さず、メニューだけで完結）。

- 起動時にも自動で静かにチェックする（ダイアログは出さない）。結果は「バージョン」メニューを開けば分かる
- 新しいバージョンが見つかっても自動ではダウンロードしない。メニュー内「ダウンロードする」を選んだ時だけ開始する
- ダウンロード完了後は「今すぐ更新して再起動(アプリ)」を選ぶまで適用されない（PC自体の再起動ではなくアプリの再起動）
- 開発モード（`npm start`）ではアップデート確認はできない仕様（インストール版限定）

## リリース手順（アップデート配布）

新しいバージョンを配布する際は、以下の手順で行う。

1. `app/package.json` の `version` を更新する（例: `0.0.2`）
2. `CHANGELOG.md` の `[開発中]` に書いていた変更点を、新しいバージョン番号の見出しの下に移動する（日付も記載）
3. GitHubのPersonal Access Token（`repo`権限）を発行し、環境変数 `GH_TOKEN` に設定する
4. `app`ディレクトリで `npm run release` を実行する（`electron-builder --win --publish always`）。ビルドしたインストーラーが GitHub Releases（`https://github.com/mumeinoapp/VirtualMixDeck/releases`）に自動でアップロードされ、`latest.yml` も生成される（これをアプリ内の「バージョン」メニューが参照する）
5. GitHub Releases画面で、そのリリースの説明欄に `CHANGELOG.md` の該当バージョンの内容を貼り付けて公開する（Draftのまま作られるので、内容を確認してから「Publish release」を押す）
6. 配布が確認できたら、はてなブログ（`https://mumeinoapp.hatenablog.com/`）に更新内容の記事を投稿する

## 既知の制約

- 音量ミキサー機能はElgato Wave Linkの起動が前提（Wave Linkが検出できない場合はミキサーへのアプリ追加ができない）
- OBS連携は配信の開始/停止・シーン切り替えのみ対応（音量操作は非対応。音量はWave Link連携側で行う）
