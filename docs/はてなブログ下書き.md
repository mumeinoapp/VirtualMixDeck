# ハードウェア不要のStream Deck風アプリ「VirtualMixDeck」を公開しました

## きっかけ

配信をしていると、こんな場面がよくあります。

- ブラウザで流しているBGMが配信に乗ってほしくないので、自分だけ聞こえるようにしたい
- 逆に、サウンドボードの効果音は配信にはちゃんと乗せたいが、自分の作業の邪魔にならないよう自分側の音量は絞りたい
- Stream Deckは便利そうだけど、専用ハードウェアを買うほどではない

これを解決するために作った「VirtualMixDeck」を公開しました。

## VirtualMixDeckでできること

- **ショートカットグリッド**：Stream Deckのような専用ハードウェアなしで、アプリ起動・URLを開く・ホットキー送信・音量操作・OBS操作をボタンに登録。複数ページに分けて管理でき、編集モードではドラッグ&ドロップでボタンの入れ替えもできます
- **ローカル/配信 独立2フェーダー**：「自分に聞こえる音量」と「配信に乗る音量」をアプリごとに完全に別々のフェーダーで調整
- **OBS操作**：OBS WebSocket経由で、配信の開始/停止・シーン切り替えをボタンから操作
- **Wave Link連携**：Elgato Wave Linkのチャンネル・ミックス（Personal Mix/Stream Mix/Chat Mix等）をグリッドから割り当てて操作
- **カスタムアイコン**：ボタンごとに絵文字風アイコンを選べるほか、自分の画像をドラッグ&ドロップして登録することも可能
- **プリセット管理**：ボタン配置やミキサー設定をまるごと名前付きで保存・切り替え

## 「ローカル/配信を独立させる」のはなぜ難しいのか

Windowsの音量ミキサーで音量を下げても、Elgato Wave Linkのミックス（Personal Mix/Stream Mixなど）の音量には一切影響しないことを実機検証で確認しました。つまり両者はもともと別経路で動いていて、特別な仮想オーディオデバイスなどを使わなくても、Windows Core Audio APIとWave LinkのAPIをそれぞれ個別に叩くだけで「独立した2本のフェーダー」が実現できます。VirtualMixDeckはこの仕組みをベースに作っています。

## 料金について

無料でも、ショートカット基本操作（アプリ起動/URLを開く/ホットキー送信/OBS操作）を2×5枠、ミキサーを2枠まで使えます。

有料版（買い切り1,480円）にすると、以下が解放されます。

- ショートカットグリッドの拡張（2×5枠 → 4×5枠）
- ミキサーエントリの無制限化
- プリセット管理（配置をまるごと保存・切り替え）
- 複数ページ

購入はアプリ内メニューの「アカウント」→「購入・ライセンス」から。既定のブラウザで決済ページを開く方式で、アプリ内にカード情報を入力する画面は持ちません。購入完了後にメールで届くライセンスキーを入力するだけで有料版に切り替わります。

## ダウンロード・アップデート確認

Windows向けインストーラーを [GitHub Releases](https://github.com/mumeinoapp/VirtualMixDeck/releases) で公開しています。ダウンロードしたインストーラーを実行するだけで使い始められます。

アプリ内メニューの「バージョン」から、新しいバージョンが出ているかいつでも確認できます。見つかった場合はメニューから「ダウンロードする」→「今すぐ更新して再起動」を選ぶだけで最新版に更新できます（自動では更新されないので安心です）。

不具合報告・ご要望は、アプリ内メニューの「アカウント」→「フィードバック」から直接送れます。

進捗・詳細は [公式サイトのアプリページ](https://mumeinoapp.pages.dev/apps/virtualmixdeck.html) でも随時更新していきます。
