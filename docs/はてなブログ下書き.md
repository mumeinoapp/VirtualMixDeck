# 【開発中】ハードウェア不要のStream Deck風アプリ「VirtualMixDeck」を作っています

## きっかけ

配信をしていると、こんな場面がよくあります。

- Discordの通知音が配信に乗ってほしくないので、自分だけ聞こえないようにしたい
- でもDiscordの音自体は配信にはちゃんと乗せたい（自分は聞こえなくていい）
- Stream Deckは便利そうだけど、専用ハードウェアを買うほどではない

これを解決するために作っているのが「VirtualMixDeck」です。

## VirtualMixDeckでできること（予定）

- **ショートカットグリッド**：Stream Deckのような専用ハードウェアなしで、アプリ起動・URLを開く・ホットキー送信・音量操作・OBS操作をボタンに登録
- **ローカル/配信 独立2フェーダー**：「自分に聞こえる音量」と「配信に乗る音量」をアプリごとに完全に別々のフェーダーで調整
- **OBS自動連携**：OBS WebSocket経由で、配信側の音声キャプチャソースの作成〜音量調整までを自動化。事前の手動セットアップ不要
- **Wave Link連携**：Elgato Wave Linkのチャンネル音量もグリッドから操作
- **カスタムアイコン・プリセット管理**：ボタンごとのアイコン変更、設定のプリセット保存

## 「ローカル/配信を独立させる」のはなぜ難しいのか

Windowsの音量ミキサーで音量を下げても、OBSの「アプリケーション音声キャプチャ」ソースの音量には一切影響しないことを実機検証で確認しました。つまり両者はもともと別経路で動いていて、特別な仮想オーディオデバイスなどを使わなくても、Windows Core Audio APIとOBS WebSocketをそれぞれ個別に叩くだけで「独立した2本のフェーダー」が実現できます。VirtualMixDeckはこの仕組みをベースに作っています。
